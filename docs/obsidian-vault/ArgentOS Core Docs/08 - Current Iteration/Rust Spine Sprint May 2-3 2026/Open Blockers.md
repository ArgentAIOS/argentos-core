# Open Blockers

## Agent Persona semantic contract

Why it matters:

Rust can store and report kernel state now, but Agent Persona still owes the meaning of that state.

Needed:

- wakefulness meanings
- intent and focus rules
- agenda source and reason
- reflection queue rules
- memory and session references
- stale state rules
- what Rust must never mutate while shadow-only

## AppForge TableForge movement

Why it matters:

Product UI work should keep moving while Rust spine work runs.

Needed:

- no-token daily-use TableForge slice
- or exact blocker with owner and proof

## Authority switch

Why it matters:

Rust is not live authority yet.

Before any switch:

- rollback command must be executable
- duplicate-prevention must be proven
- installed daemon canary must be proven
- dashboard or desktop smoke must show the state clearly
- operator must explicitly approve promotion

## Production daemon rollout

Why it matters:

Current proof is local and disposable.

Still not done:

- production installed daemon rollout
- live service control
- live connector execution
- customer or OAuth data proof
